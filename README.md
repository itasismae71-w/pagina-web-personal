# Página Web Personal

## Descripción
Proyecto web personal desarrollado de manera colaborativa para la gestión y control de versiones con Git y GitHub.

## Objetivo
Desarrollar una aplicación web funcional aplicando flujos de trabajo colaborativos mediante ramas, commits estructurados, Pull Requests y resolución de conflictos.

## Funcionalidades
- Estructura base en HTML5 y estilos CSS.
- (En desarrollo) Funcionalidades adicionales por integrar.

## Tecnologías utilizadas
- HTML5
- CSS3
- Git
- GitHub
- Visual Studio Code
